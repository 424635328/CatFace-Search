# 诊断记录：CALFW 不是猫脸数据集

**结论先行**：HuggingFace 上 `cat-claws/face-verification` 数据集的 `calfw` split（6000 对，112×112）**不包含猫脸，包含的是人脸**。任何基于它构建的"猫脸验证基准"产出的数字都是无意义的。

**发现日期**：2026-10-05

---

## 1. 触发调查的现象

在 CALFW 上跑完整验证协议（6000 对，TTA identity+hflip，余弦相似度）后得到：

| 配置 | ROC-AUC | EER | TAR@FAR=0.01 |
|---|---|---|---|
| baseline-resnet50 | 0.5876 | 0.4417 | 0.0247 |
| dinov2-vits14 | 0.6233 | 0.4107 | 0.0340 |
| dinov2-vitb14 | 0.6375 | 0.3933 | 0.0297 |
| *平凡基线：原始像素余弦（32×32）* | *0.5508* | *0.4653* | *0.0300* |
| *平凡基线：颜色直方图交集* | *0.5288* | *0.4782* | *0.0113* |

**所有模型都接近随机。** 这个绝对值不可信——猫脸验证的已发表工作 AUC 在 0.98 以上。

关键判断：**AUC 0.59–0.64 这个数值本身不合理，必须查清，而不是接受或忽略。** 于是用三个互相独立的观察者对协议做了审计。

## 2. 审计证据链

### 2.1 数据本身是干净的（所以不是数据损坏）

- 6000 对，标签严格平衡：3000 同 / 3000 异
- 全部图像恰好 112×112 RGB，无一例外
- 600 张抽样图像字节级唯一，无重复
- 导出 CSV 与 parquet 标签计数一致（`matches_parquet_counts: true`）
- 余弦分数与标签对齐正确（相似度矩阵 2000×2000 上 `exact_pair_is_argmax_rate` 与分数分布自洽）

**排除了**：标签翻转、导出错位、图像损坏、重复泄漏。

### 2.2 统一尺寸是第一个可疑信号

所有图像**恰好** 112×112。真实野外照片不可能天然统一尺寸——这是从固定尺寸源裁切/缩放的特征。真实猫脸数据集（如 cat-individuals）图像尺寸是发散的。

### 2.3 ImageNet 分类器：0/600 被判为猫

用 torchvision ResNet-50 (IMAGENET1K_V2) 跑 600 张：

- 判为猫类（tabby/tiger cat/Persian/Siamese/Egyptian）的图像：**0**
- 五类猫的平均概率质量：**0.0027**
- 概率质量低于 0.05 的图像占比：**100%**

Top-1 预测类别分布：

| 类别索引 | 名称 | 张数 |
|---|---|---|
| 906 | Windsor tie（温莎领带） | 244 |
| 678 | neck brace（颈托） | 155 |
| 683 | oboe（双簧管） | 80 |
| 699 | panpipe（排箫） | 24 |
| 400 | academic gown（学位袍） | 15 |
| 903 | wig（假发） | 13 |
| 652 | military uniform（军装） | 12 |
| 715 | pickelhaube（尖顶盔） | 7 |
| 439 | bearskin（熊皮帽） | 4 |

这些是**人脸裁剪图在 ImageNet 上的经典混淆类别**（衣领、帽子、头发、贴近脸部的物体）。真实的 112×112 猫脸会被高置信度判为 `tabby` 或 `Egyptian cat`。

### 2.4 人群专用检测器：100% 命中 —— 决定性证据

用 OpenCV YuNet **人脸**检测器（对人脸特异，对猫脸不响）跑 300 张：

```
images_with_human_face: 300 / 300
human_face_rate: 1.0
mean_face_confidence: 0.9203
```

### 2.5 阳性对照 —— 证明审计工具本身可信

同一脚本、同一阈值跑 **151 张确知是猫**的图像（Oxford-IIIT Pet 猫图，按训练集标注优先挑选）：

```
images_with_human_face: 10 / 150
human_face_rate: 0.0667
mean_face_confidence: 0.0537
```

| 语料 | 人脸检出率 | 平均置信度 |
|---|---|---|
| 已知猫图（对照） | **6.7 %** | 0.054 |
| CALFW | **100 %** | 0.920 |

检出率差 15 倍，置信度差 17 倍。结论无歧义，且说明审计工具没有系统性误报。

### 2.6 领域专精模型也无法区分 —— 排除"我们的编码器太弱"

用 `AvitoTech/DINO-v2-small-for-animal-identification`（在 1 904 157 张照片 / 695 091 个猫狗个体上微调过）跑 2000 对：

```
roc_auc: 0.5613
eer: 0.4667
score_separation (正类均值 - 负类均值): 0.038
```

一个**专门为区分猫狗个体而训练**的模型在此任务上处于随机水平。如果这些对真的是"同猫/异猫"，它不可能只做到 0.56。这直接排除了"我们的骨干不够强"这一解释。

## 3. 合理解释

`calfw` 很可能是 **Cat-Aligned LFW** 的缩写——把 LFW（Labeled Faces in the Wild，人脸验证数据集）的图像统一缩放成 112×112 的产物。该 HF 仓库同时提供 `lfw` / `agedb_30` / `cfp_ff` / `cfp_fp` / `cplfw` 等**全部都是人脸验证基准**的 split，`calfw` 与它们并列，这符合上述解释。

**注意**：不应断言为恶意——命名歧义加上自动转换是更可能的成因。但无论成因如何，**这批数据不能用于猫脸任务**。

另注：原论文的真实 CALFW（猫脸验证）数据集**并未公开分发**，公开渠道拿到的是这个同名异物。

## 4. 原始数字的正确解读

原始结果里唯一有信息量的是**相对排序**：

```
ResNet-50 (0.5876) < DINOv2-S (0.6233) < DINOv2-B (0.6375)
```

三个模型在这批（人脸的）数据上保持一致且符合"容量越大越好"的排序，说明**评测框架对模型的排序是合理的**。但它对猫脸身份没有任何证据力。

**因此：这组数字不得作为猫脸验证结果报告。** 协议已从基准中撤出。

## 5. 处置

1. **撤出** CALFW 验证协议；`docs/diagnostics/calfw-*.json` 保留为审计记录。
2. **替换**：猫脸验证能力改在**带身份标注的画廊式语料**上报告——`timost1234/cat-individuals`（13 536 张 / 518 只个体猫，CC BY 4.0），该语料同样经过物种审计。
3. **制度化**：任何新数据源进入基准前，先过 `tools/audit_species.py` 与 `tools/audit_content.py`。

## 6. 方法论教训（可复用）

1. **数据集的名称和 dataset card 不构成其内容的证据。** 必须实测。
2. **绝对分数远低于已发表 SOTA 时，先审数据，再调模型。** 接近随机的分数更可能是数据错了，而不是模型弱。
3. **用独立且无标签的观察者审计**：平凡基线（定下下限）、通用分类器（看内容）、**物种专用检测器**（看population）。三者互相独立，结论一致才可信。
4. **一定要做阳性对照。** 没有"已知猫图检出率 6.7%"这一对照，100% 的检出率无法排除"检测器到处乱响"。
5. **领域专精的参考模型是最便宜的判别工具**：它能把"数据难"与"数据错"区分开，成本只是下载一个 86 M 模型跑一次。
